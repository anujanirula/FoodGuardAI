# FoodGuardAI

## Folder Structure

```
FoodGuardAI
│
├── frontend
├── backend
├── prompts
├── datasets
├── docs
```

- **frontend** — Frontend application for FoodGuardAI.

- **prompts** — Prompt templates used by FoodGuardAI's AI models.
- **datasets** — Datasets used for training and evaluating FoodGuardAI models.
- **docs** — Project documentation.
- **presentation** — Presentation materials.
